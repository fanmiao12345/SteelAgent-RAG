1. LLM 调用要求

---

请实现 llm_client.py，用于调用大模型接口。

大模型接口格式如下：

请求地址：

POST {LLM_API_URL}

请求 Headers：

Authorization: Bearer {LLM_API_KEY}
Content-Type: application/json

请求 Body 示例：

{
"model": "mimo-v2.5-pro",
"messages": [
{
"role": "system",
"content": "你是一个面向钢铁行业的智能体助手。"
},
{
"role": "user",
"content": "高炉煤气利用率下降可能是什么原因？"
}
],
"temperature": 0.3
}

请封装一个 LLMClient 类，至少包含：

1. chat(messages: list[dict], temperature: float = 0.3) -> str
2. build_messages(system_prompt: str, user_prompt: str) -> list[dict]
3. fallback_chat(prompt: str) -> str

要求：

1. 如果 LLM_API_KEY 为空，使用 fallback_chat 返回模板化回答。
2. 如果接口请求失败，也要捕获异常并返回可读错误信息。
3. 不要让服务因为大模型接口异常而崩溃。
4. 使用 requests 或 httpx 调用接口。
5. 默认 timeout 设置为 60 秒。
6. 返回内容需要从接口响应中解析 assistant 的 message.content。
7. 项目中所有大模型调用都必须通过 llm_client.py。

---

2. Embedding 调用要求

---

请实现 embedding_client.py，用于调用 Embedding 接口。

Embedding 接口配置如下：

EMBEDDING_API_URL=http://10.199.194.246:11434/api/embeddings
EMBEDDING_MODEL_NAME=bge-m3

请求地址：

POST {EMBEDDING_API_URL}

请求 Body 示例：

{
"model": "bge-m3",
"prompt": "高炉炼铁是钢铁生产中的重要流程。"
}

请封装一个 EmbeddingClient 类，至少包含：

1. embed_text(text: str) -> list[float]
2. embed_documents(texts: list[str]) -> list[list[float]]

要求：

1. 使用 requests 或 httpx 调用 Embedding 接口。
2. 默认 timeout 设置为 60 秒。
3. 如果接口返回格式中包含 embedding 字段，则读取该字段。
4. 如果接口调用失败，需要抛出清晰的异常提示。
5. RAG 模块中的向量化必须调用这个 EmbeddingClient。
6. 不要再默认使用 SentenceTransformers，除非作为 fallback 方案。
7. 如果 Embedding 接口不可用，需要提示用户检查 EMBEDDING_API_URL 是否可访问。
8. 项目中所有 Embedding 调用都必须通过 embedding_client.py。

五、用户角色与权限
=========

请设计简单但可运行的角色权限控制。

系统包含以下角色：

1. visitor

   * 访客
   * 只能查看公开行业知识
   * 不能使用生产数据分析工具
   * 不能查看内部操作规程

2. operator

   * 一线操作员
   * 可以查看公开知识、操作规程、安全制度、设备维护建议
   * 可以使用钢材重量计算工具
   * 可以使用故障辅助分析工具

3. engineer

   * 工程师
   * 可以查看工艺知识、设备故障、能耗、碳排放说明
   * 可以使用大部分分析工具
   * 可以查看技术类文档

4. manager

   * 管理人员
   * 可以查看生产指标、成本、能耗、碳排放汇总信息
   * 可以使用生产统计工具
   * 可以使用能耗成本和碳排放工具

5. admin

   * 管理员
   * 可以查看全部文档
   * 可以使用全部工具

文档安全等级包括：

1. public
2. internal
3. confidential

访问规则：

1. visitor 只能访问 public
2. operator 可以访问 public、internal
3. engineer 可以访问 public、internal、confidential 中的工艺和设备类文档
4. manager 可以访问 public、internal、confidential 中的统计、成本、能耗类文档
5. admin 可以访问全部内容

3. 工具调用模块

---

请实现 tools 目录。

至少包含以下工具：

1. steel_weight_calculator.py

功能：
计算钢材理论重量。

支持：

* 钢板
* 圆钢
* 钢管
* 螺纹钢

示例：
厚度 10mm，宽度 2m，长度 6m 的钢板重量是多少？

计算逻辑：
体积 = 厚度 × 宽度 × 长度
重量 = 体积 × 密度
钢材密度默认 7850 kg/m³

2. carbon_emission_calculator.py

功能：
估算钢铁生产碳排放。

输入：

* production_ton
* emission_factor

示例：
产量 1000 吨，排放因子 1.8 tCO2/t-steel
输出：
1800 tCO2

3. energy_cost_calculator.py

功能：
计算能耗成本。

输入：

* electricity_kwh
* electricity_price
* gas_m3
* gas_price

输出：
总能耗成本

4. fault_diagnosis_tool.py

功能：
根据设备名称和故障现象给出可能原因。

示例：
设备：连铸机
故障现象：结晶器液位波动

输出：
可能原因包括拉速不稳定、塞棒控制异常、保护渣状态异常、液位检测异常等。

5. production_indicator_tool.py

功能：
读取 data/production/production_sample.csv，计算生产指标。

指标包括：

* 日产量
* 合格率
* 单吨电耗
* 单吨成本
* 碳排放强度

十三、运行要求
=======

请确保项目可以按以下步骤运行。

第一步：创建虚拟环境

python -m venv venv

第二步：激活虚拟环境

Windows：

venv\Scripts\activate

Linux / macOS：

source venv/bin/activate

第三步：安装依赖

pip install -r requirements.txt

第四步：复制环境变量文件

Windows：

copy .env.example .env

Linux / macOS：

cp .env.example .env

第五步：编辑 .env

示例：

LLM_API_URL=https://token-plan-cn.xiaomimimo.com/v1/chat/completions
LLM_MODEL_NAME=mimo-v2.5-pro
LLM_API_KEY=你的真实APIKey

EMBEDDING_API_URL=http://10.199.194.246:11434/api/embeddings
EMBEDDING_MODEL_NAME=bge-m3

VECTOR_STORE_PATH=storage/vector_index
MEMORY_PATH=storage/memory
AUDIT_LOG_PATH=logs/audit.log

注意：

1. LLM_API_KEY 不要写死在代码里。
2. LLM_API_KEY 不要提交到 Git。
3. 如果 LLM_API_KEY 为空，系统应使用 fallback 模式运行。
4. 如果 Embedding 接口不可用，导入知识库时需要给出清晰提示。

第六步：导入知识库

python scripts/ingest_docs.py

第七步：启动服务

uvicorn main:app --reload --host 0.0.0.0 --port 8000

第八步：访问接口文档

http://127.0.0.1:8000/docs
